# StudyNet — CSIR NET Life Science

A free, static course website starter.

## Files
- `index.html` — website structure
- `style.css` — responsive design
- `script.js` — lecture list and YouTube embedding

## Add more lectures
Open `script.js` and add another object to the `lectures` array:

{
  id: "YOUTUBE_VIDEO_ID",
  title: "Lecture title",
  description: "Short description"
}

For a YouTube link like:
https://youtu.be/ABC123XYZ

the video ID is:
ABC123XYZ
